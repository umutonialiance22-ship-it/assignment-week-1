# Recipe Page - Week 1 Git Workflow

A simple recipe page built to practice a professional Git and GitHub workflow.

## Technologies Used
- HTML5
- CSS3
- Git & GitHub

## Setup
1. Clone the repository:
   git clone https://github.com/umutonialiance22-ship-it/assignment-week-1
2. Open `index.html` in your browser.

## Git Workflow
- Work planned with GitHub Issues and a Project board
- Each issue developed on its own feature branch
- Changes merged through Pull Requests (`Closes #n`)
- No direct commits to `main`
- Merge conflict intentionally created and resolved
